# 10. Пользовательский интерфейс (User Interface)

## 10.1 Дизайн-система и типографика лендинга `heuristics.ru`

Дизайн сайта выполнен в строгом академическом стиле («Институциональный / Research Institute») с акцентом на типографику и физику алгоритмов:
* **Шрифтовая пара:** 
  * `EB Garamond` (заголовки, метафорические цитаты, академическая подача)
  * `Inter` (основной интерфейсный текст, навигация)
  * `JetBrains Mono` (терминалы, формулы, технические метрики и листинги)
* **Палитра:**
  * Фоновый цвет: `#FBFBFA` (тёплая бумага)
  * Текст: `#1C1917` (глубокий угольный)
  * Акцент совпадения (Match): `#00B48C` (изумрудно-зелёный)
  * Акцент гэпа (Gap/Alert): `#C74634` (терракотово-красный)
