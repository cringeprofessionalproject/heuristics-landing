# 11. Риски и технический долг (Risks and Technical Debts)

## 11.1 Выявленные риски и узкие места

| Категория | Риск / Проблема | Влияние | Рекомендация по устранению |
|---|---|---|---|
| **DNS / SSL** | Проверка `curl` выявила предупреждение Hostname mismatch при прямом доступе к `heuristics.ru` без www в некоторых клиентах | Среднее | Проверить и синхронизировать Apex A-записи GitHub Pages и CNAME `www.heuristics.ru`. |
| **CI/CD** | Ручной `rsync` и запуск команд SSH для деплоя бэкенда вместо GitHub Actions / автоматизированного пайплайна | Среднее | Настроить GitHub Actions workflow с self-hosted runner или SSH action для автодеплоя на VPS по пушу в тег/ветку. |
| **Секреты** | Хранение API-ключей в `.env` файлах на сервере и локально без централизованного Vault | Низкое / Среднее | Использовать `bitrix24-safe` или зашифрованные секреты в репозитории (git-secret/SOPS). |
| **Бэкапы БД** | Бэкапы PostgreSQL запускаются вручную через `pg_dump` | Среднее | Настроить cron-задачу на VPS для ежедневного архивирования `splash2` и выгрузки в S3 / outbox. |
| **Разделение прав** | Использование единого пользователя `makuev` для всех сервисов на сервере | Низкое | Изолировать PM2 процессы под отдельным сервисным пользователем `apprunner`. |
