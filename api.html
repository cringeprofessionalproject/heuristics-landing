§ IV — API Reference

SPLASH
External API

Подключайте свои модули к SPLASH 2.0. Полный read-only доступ к каталогу, LLM-прокси с автоматическим failover, изолированное хранение результатов.

Быстрый старт

Все запросы требуют заголовок X-API-Key. Ключ выдаётся администратором системы.

Base URL: https://splash.heuristics.ru/api/ext/v1
bash
# Проверить ключ
curl -H "X-API-Key: ext_ваш_ключ" \
  https://splash.heuristics.ru/api/ext/v1/me

# Получить товары
curl -H "X-API-Key: ext_ваш_ключ" \
  "https://splash.heuristics.ru/api/ext/v1/products?limit=5"

Архитектура

Три изолированных канала с разным уровнем доступа:

📖 Чтение

Read-only доступ к каталогу SUPRLAN: товары, параметры, аналоги, метакатегории. Основная БД не затрагивается.

🤖 LLM Proxy

Промпты через наш API — нейросеть с автоматическим переключением на резервную при сбое. Rate limit: 50 запросов/час.

💾 Запись

Результаты сохраняются в изолированную БД splash_modules. Основная система полностью защищена.

схема
Ваш модуль ──► X-API-Key ──► ext-auth ──► Rate Limiter
                                         │
                       ┌─────────────────┼─────────────────┐
                       ▼                 ▼                 ▼
                 splash2 DB        LLM (DS/Wormsoft)  splash_modules DB
                 (SELECT only)     (proxy + failover)  (INSERT/UPDATE/DELETE)

Аутентификация

Каждый запрос должен содержать заголовок X-API-Key со значением ключа.

Ключ начинается с префикса ext_ и содержит 48 hex-символов. На сервере хранится только SHA-256 хеш — если ключ утерян, нужно создать новый.

request
GET /api/ext/v1/me HTTP/1.1
Host: splash.heuristics.ru
X-API-Key: ext_6b59c4561c69467922f9b6524415b6d5...
response — 200

LLM Proxy

Отправляйте промпт — получайте ответ от нейросети. При сбое основного провайдера система автоматически переключается на резервный.

МетодПутьОписание
POST/llm/chatПромпт → ответ от нейросети

Тело запроса

ПолеТипОбяз.Описание
promptstring✅Текст промпта
systemstring—Системный промпт
max_tokensint—Максимум токенов (default 8000, max 16000)
temperaturefloat—Температура генерации (0–1, default 0)
request
POST /api/ext/v1/llm/chat
Content-Type: application/json
X-API-Key: ext_ваш_ключ

{
  "system": "Ты — эксперт по кабельным системам.",
  "prompt": "Напиши описание: Коннектор RJ-45 FTP Cat.5e",
  "max_tokens": 4000,
  "temperature": 0
}
response — 200
{
  "model": "deepseek-ai/deepseek-v4-pro",
  "content": "# Коннектор RJ-45\n\nПрофессиональный коннектор...",
  "thinking": "Размышления модели (если поддерживается)...",
  "tokens": { "total": 2100, "prompt": 600, "completion": 1500 },
  "time_ms": 8500
}
⏱ Rate Limit: 50 LLM-запросов в час. Заголовки ответа X-RateLimit-Limit и X-RateLimit-Remaining показывают остаток.

Общие параметры

Пагинация

Эндпоинты /products и /cards поддерживают параметры limit (max 200) и offset. В ответе возвращается total.

Rate Limit заголовки

LLM-эндпоинт возвращает заголовки:

ЗаголовокОписание
X-RateLimit-LimitМаксимум LLM-запросов в час (50)
X-RateLimit-RemainingОсталось запросов в текущем окне

Ошибки

Все ошибки возвращают JSON { "error": "описание" }.

КодЗначениеКогда
401UnauthorizedНет заголовка X-API-Key или ключ не найден
403ForbiddenКлюч деактивирован
404Not FoundТовар или карточка не найдены
429Rate LimitedПревышен лимит LLM-запросов (50/час)
500Server ErrorВнутренняя ошибка (БД, LLM, сеть)

Полный пример на Python

python
import requests

API = "https://splash.heuristics.ru/api/ext/v1"
KEY = "ext_ваш_ключ"
H = {"X-API-Key": KEY}

# 1. Проверить подключение
me = requests.get(f"{API}/me", headers=H).json()
print(f"Подключен: {me['name']}, LLM осталось: {me['usage']['llm_remaining']}")

# 2. Получить товары категории
products = requests.get(f"{API}/products", headers=H, params={
    "category": "patch_cords", "limit": 10
}).json()

for p in products["products"]:
    article = p["article"]

    # 3. Полные данные
    data = requests.get(f"{API}/products/{article}", headers=H).json()

    # 4. Генерация через LLM
    resp = requests.post(f"{API}/llm/chat", headers=H, json={
        "system": "Ты эксперт по СКС. Пиши профессионально.",
        "prompt": f"""Продукт: {data['name']}
Категория: {data['meta_category']}
Параметры: {data['key_params']}
Конкуренты: {[c['name'] for c in data.get('competitors', [])]}

Создай маркетинговое описание для маркетплейса.""",
        "max_tokens": 4000
    }).json()

    # 5. Сохранить результат
    requests.post(f"{API}/cards", headers=H, json={
        "article": article,
        "module_name": "my_generator_v1",
        "sections": {"description": resp["content"]},
        "metadata": {"model": resp["model"], "tokens": resp["tokens"]}
    })

    print(f"✅ {article}: {len(resp['content'])} символов")

Контекст для AI-агентов

Скопируйте блок ниже и передайте его AI-агенту (Claude, GPT, Gemini и др.) как системный контекст. Агент сможет подключиться к API без дополнительных инструкций.

## SPLASH External Module API Base URL: https://splash.heuristics.ru/api/ext/v1 Auth: Header X-API-Key with provided key ### Available Endpoints: - GET /me — check key status and usage - GET /categories — list product categories (slug + display_name) - GET /products?limit=N&offset=M&category=slug&search=text — list products - GET /products/:article — full product data (params, description, competitors, lineup) - POST /llm/chat {system, prompt, max_tokens, temperature} — send prompt to LLM - POST /cards {article, module_name, sections, metadata} — save generated card - GET /cards?limit=N&offset=M — list saved cards - GET /cards/:article?module_name=X — get specific card - DELETE /cards/:article?module_name=X — delete card - PUT /data/:key {value: any} — save arbitrary JSON config - GET /data/:key — retrieve saved data ### Rate Limits: - LLM: 50 requests/hour, max 16000 tokens/request - Other endpoints: unlimited - Headers: X-RateLimit-Limit, X-RateLimit-Remaining ### Key Data Available Per Product: - article, name, brand, price, stock_qty - meta_category, key_params (technical specs), extracted_params - raw_description (scraped from website, up to 5000 chars) - competitors[] (analog products with prices and params and score) - lineup[] (same-category products from same brand for comparison) ### Storage: - POST /cards saves to isolated DB (not main SPLASH) - Key uniqueness: (api_key_id, article, module_name) - Re-POST same article+module_name = UPDATE (upsert) - PUT /data/:key saves arbitrary JSON config per key ### Error Format: All errors return { "error": "description" } - 401: missing or invalid API key - 403: key deactivated - 404: product or card not found - 429: LLM rate limit exceeded (50/hour) - 500: internal error
